# DaVinci Resolve 婚纱短片工作流

## 安全建版

- 创建新项目或新时间线，不覆盖原素材、已验证成片或旧时间线。
- 优先用 Resolve 官方 Python/Lua Scripting API 执行导入、建时间线、精确帧切点、基础变换、CDL 调色、渲染与状态回读；API 未暴露的面板操作再用界面控制。
- 在空时间线上使用帧区间顺序追加视频。先将切点量化到输出帧率；60 fps 时使用整数帧。
- 用独立配乐替代相机原声时，将视频以 `mediaType=1` 追加，再将音频以 `mediaType=2` 放在时间线实际起始帧。在修改音轨结构前先读取并保存 `timeline.GetStartFrame()`，不假设起始帧是 0。

## 重拍动作反差

1. 从音乐起音或频谱流中选出强拍，再量化到时间线帧格。
2. 为每个强拍分配差异明显的动作/景别：全身静态、正脸近景、裙摆、半身手势、俯身或转身。
3. 可打乱原时间轴。少量重复时，换用不同动作相位或约 1.02–1.05 的轻微景别差，避免完全复制感。
4. 在强拍帧后约 3–5 帧抽帧，确认动作已进入可读姿态，而不是过渡模糊帧。

## 净白肤色与逐段匹配

1. 选定一个脸部曝光正常、婚纱花纹未过曝的基准镜头。
2. 先让全部镜头采用一致的低强度观感基准：轻提中间调、降低暖黄与红润、轻降饱和度，保留高光滚降和花纹。节点结构可以复制，但每个片段的参数必须独立，不能链接或共享一级调色、遮罩与局部调整。
3. 对偏红近景小幅降红或加蓝，对偏黄绿片段降绿/黄并轻加蓝，对偏暗片段只调中间调。不让每段独立“变好看”而破坏整体一致性。
4. 在每个切点后抽同一时间偏移的帧，并列检查脸部明度、肤色色相、婚纱白场和背景中性灰。

### 逐片节点预设

建立节点前读取 [node-presets.md](node-presets.md)，在 3／5／7／9 四档中选择最小够用的预设。用户没有指定时，单人婚纱默认使用 7 节点“婚纱精修”；复杂背景、多人独立肤色或独立输出管理时使用 9 节点。不要给转场、调整片段、闪光层或纯特效层套用人物调色节点。

四档通过合并或拆分以下职责模块控制节点数：降噪、白平衡曝光、明暗层次、色彩密度、肤色、Face Refinement、背景局部、Look、Finish/Output。色彩管理工程不重复添加 CST；多人超过两人时允许记录为“9+ 扩展”，不能为了固定节点数而让多人共用一个皮肤遮罩。

执行规则：

- 每个片段都拥有自己的节点实例。只统一节点顺序和最终观感，不强行统一数值。
- 在已有调色片段上补节点时，先建时间线副本或版本；逐片按时间码定位，插入后立即回读节点数量、顺序、标签和工具，确认没有把多个节点误加到同一片段。
- 新建结构后先完成一级匹配，再处理肤色、面部和背景局部，最后制作 Look 与 Finish；不要用 Look 掩盖曝光、肤色或遮罩问题。
- 完成后不用连续播放作主要判断。按全身、半身、近景分别抽取多个随机静帧，并在切点前后检查曝光、肤色、婚纱纹理、遮罩连续性和背景中性。

### Magic Mask 2 皮肤二级统一

1. 先把用户已经调好的前段镜头按景别分成参考组：全身、半身/手势、正脸近景。后段镜头只复制同景别参考的完整调色，不把转场、闪光或推移效果层当成参考或目标。
2. 肤色放在独立串行节点。对单一人物皮肤默认只在脸部皮肤设置一个正跟踪点并立即跟踪；不要一开始在面部、肩颈和手臂密集打点，点数过多会显著增加神奇遮罩计算负担，并可能使跟踪长时间停在 0%。只有单点结果明确漏选时才补充最少量样本。保留一级平衡节点，便于单独开关和回退肤色效果。
3. 按连续镜头段分配跟踪点。如果一个时间线片段实际包含人物位置突变的多个不连续镜头，必须分别进入每个镜头段，在该段人物脸部皮肤各设置一个正跟踪点并单独确认跟踪；不要让前一段的点跨越跳变，也不要因为它们位于同一个时间线片段就只处理第一段。连续单一镜头仍保持一个点。
4. 可用 Resolve MCP 的 `safe_copy_grade` 按时间线项目 ID 批量复制参考调色；先 `dry_run` 检查目标，再执行确认令牌保护的复制。复制会替换目标的完整节点图，因此必须先建时间线版本或分析运行档案。
5. 复制 Magic Mask 节点后，不把参考镜头的跟踪缓存视为有效结果。对每个目标镜头执行 `create_magic_mask(mode="BI")` 或在界面中“向前跟踪并向后跟踪”，让遮罩按该镜头重新分析；长镜头逐个处理，不并行启动多个跟踪任务。
6. 若 MCP 跟踪调用长时间无返回，不要重复提交。先等待 Resolve 当前分析结束，再检查遮罩叠加层和节点工具；必要时在调色页停止跟踪、重新选择目标镜头后单独重算。
7. 参数以参考镜头为准，不机械套固定数值。面向亚洲婚纱审美时，以白皙、干净、通透且保留少量自然血色为目标；避免灰白、偏青和塑料感，也不要连带提白婚纱或背景。需要轻度净白时，可把色温约 `-60`、中间调细节约 `-2` 至 `-2.5` 作为克制起点，再按切点抽帧修正；避免手臂与面部明度脱节或磨皮失真。
8. 验收时不要依赖调色界面播放预览。为每个主体镜头抽取多个随机时间点截图；对被指出的时间点至少检查前后各约 0.5 秒与目标帧，并列核对脸部肤色、人物位置连续性、遮罩连续性、婚纱纹理与背景是否被误调。遮罩穿帮的镜头只修该镜头，不改共享参考。

### 多人物与差异化肤色

1. 不凭画面外貌自动判断人物的人种、族裔或审美偏好。优先使用客户明确说明的身份、市场和风格要求；没有明确要求时，保留每个人原有肤色之间的自然关系，只校正曝光、偏色和镜头不一致。
2. 客户明确要求健康日晒或小麦色风格时，采用克制的暖金、古铜方向：轻暖中间调与高光、控制红色和橙色饱和度，保留皮肤纹理，避免把肤色推成橘红、脏黄或统一套棕色滤镜。这是一种指定风格，不按“欧美人物”自动套用。
3. 同一画面出现多个人物时，为每个人建立独立的皮肤节点和 Magic Mask；每个连续镜头段中，每个人脸部皮肤各设置一个正跟踪点。分别调整色温、色调、明度、饱和度和细节，不让一个人的遮罩或参数影响另一个人。
4. 多人镜头先统一场景曝光和白平衡，再逐人修正肤色；不要把不同人物强行调成完全相同的亮度或色相。验收时分别放大检查每张脸、颈肩与手臂的一致性，并确认婚纱、背景和另一人物未被误选。

## 逐段扶正

- 使用门框、窗框、顶棚、墙缝或地面作为参照，不使用人物肩线判断相机倾斜。
- 为每段分别设置旋转。常规修正约 0°–0.8°；转向与数值以环境线垂直/水平为准。
- 旋转片段使用约 1.02 倍等比缩放遮边。近景或黑背景无线条参考时保持 0°，避免为了“统一数值”破坏构图。

## 渲染验收

- 导出前保存项目，渲染后回读任务状态，不以“已加入队列”当作完成。
- 若渲染任务报“无法加载项目”，不得把队列创建成功当成交付完成。先保存并导出 `.drp`，以明确名称导入独立渲染副本，载入正确时间线、清空失败队列后重新建立任务；只有任务状态为完成且输出文件可读时才交付。保留原项目和原成片不动。
- 校验实际时长、竖屏尺寸、帧率、视频编码、立体声音轨和容器。
- 抽取开场、每个强拍后 3–5 帧和结尾帧生成联系表。同时检查动作反差、肤色一致性、婚纱纹理、环境线、旋转边缘、头顶与手势。
